# FlowForge Plumbing Website

A premium, responsive plumbing-business website template built for local service businesses in Bengaluru.

## Project overview

FlowForge is designed as a reusable plumbing website system with:

- Premium responsive UI
- Mobile-first layout
- Emergency call-to-action flow
- WhatsApp integration
- Service pages
- Project showcase
- Customer reviews
- Service-area pages
- FAQ section
- Booking form
- Contact form
- SEO-ready metadata
- Custom 404 page
- Sitemap and robots configuration

## Technology

This version uses:

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive CSS Grid and Flexbox
- Google Fonts
- Unsplash image URLs for development imagery

## Run locally

No build tool is required for the current version.

You can:

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Or use the Live Server extension in Visual Studio Code.

For the best development experience, use Live Server so that page navigation and asset loading work consistently.

## Forms

The contact, review and booking forms currently demonstrate:

- Required-field validation
- Success messages
- Error messages
- Responsive form layouts

They do not currently store or send submissions.

For production, connect the forms to one of these:

- Formspree
- Web3Forms
- EmailJS
- Netlify Forms
- A custom serverless API
- Supabase
- Resend

## Deployment

This static website can be deployed using:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

After deployment:

1. Connect the client domain.
2. Replace the sitemap domain.
3. Update `robots.txt`.
4. Add Google Search Console.
5. Add Google Analytics if required.
6. Test all phone and WhatsApp links.
7. Test all forms.
8. Test the website on mobile devices.
